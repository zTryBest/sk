## 缺陷严重程度

| 级别 | 定义 |
|------|------|
| critical | 核心功能不可用，无变通方案 |
| major | 重要功能异常，有变通方案 |
| minor | 非核心功能异常或体验问题 |
| trivial | 文案、样式等细节问题 |
