#### 获取资源的历史在线记录

**接口说明**

> 获取资源的历史在线记录接口

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/nms/v1/online/history_status

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| indexCode | body | string | true | 资源编码，从[获取资源列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-资源信息接口#cbc52c56)接口获取返回报文中的indexCode字段 |
| startDate | body | string | false | 开始日期，yyyy-MM-dd格式 |
| endDate | body | string | false | 结束日期，yyyy-MM-dd格式 |
| pageNo | body | integer | false | 页码,从1开始 |
| pageSize | body | integer | false | 页大小,正整数，最大值1000，默认值500 |
| resourceType | body | string | true | 资源类型,参考[附录A.64 网管资源类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#eb9b240e) |

**请求参数举例**
```json
{
    "indexCode": "ce91c758-5af4-4539-845a-1b603746c55",
    "startDate": "2018-01-02",
    "endDate": "2019-01-03",
    "pageNo": 1,
    "pageSize": 20,
    "resourceType": "encodeDevice"
}
```

**返回参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.other.1 资源目录错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#b3d660a8) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +total | body | number | false | 总条数 |
| +list | body | object[] | false | 在线记录列表 |
| ++collectTime | body | string | false | 状态采集时间，时间格式为ISO格式 |
| ++online | body | number | false | 监控点在线状态，0-离线，1-在线 |

**返回参数举例**
```json
{
    "code": "0",
    "msg": "Operation succeeded",
    "data": {
        "total": 1,
        "list": [
            {
                "collectTime": "2018-12-28T10:21:40.000+08:00",
                "online": 1
            }
        ]
    }
}
```
