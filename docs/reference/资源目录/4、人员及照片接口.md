##### 根据人员唯一字段获取人员详细信息

**接口说明**

> 获取人员信息接口，可以根据实名标识(证件号码、人员ID、手机号码、工号)来精确查询人员信息，并返回总数量。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

> POST

| paramName | body | string | true | 参数名<br>certificateNo：证件号码，从[获取人员列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员及照片接口#d24aac3e)接口返回报文中的certificateNo字段；<br>personId：人员Id，从[获取人员列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员及照片接口#d24aac3e)接口返回报文中的personId字段；<br>phoneNo：手机号码，从[获取人员列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员及照片接口#d24aac3e)接口返回报文中的phoneNo字段；<br>jobNo：工号，从[获取人员列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员及照片接口#d24aac3e)接口返回报文中的jobNo字段。 |
