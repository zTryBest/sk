##### 查询组织列表v2

**接口说明**

> 根据不同的组织属性分页查询组织信息。<br>查询组织列表接口可以根据组织唯一标识集、组织名称、组织状态这些查询条件来进行高级查询；若不指定查询条件，即全量获取所有的组织信息。返回结果分页展示。<br>注：若指定多个查询条件，表示将这些查询条件进行"与"的组合后进行精确查询。<br>根据"组织名称orgName"查询为模糊查询。<br>根据父组织查询子孙组织，为便于构建组织树，会返回没有权限的父组织，通过available为false区分； 如果额外指定了其它字段，为在返回数据的基础上进一步过滤出符合条件的数据。<br>

**接口版本**

> v2

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/resource/v2/org/advance/orgList

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| orgName | body | string | false | 组织名称，如默认部门 |
| orgIndexCodes | body | string | false | 组织唯一标识码集合<br>多个值使用英文逗号分隔，不超过1000个，从[获取组织列表](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-组织信息接口#b8da83b5)接口获取返回参数orgIndexCode |
| pageNo | body | integer | true | 当前页码<br>当前页码需大于0（pageNo>0） |
| pageSize | body | integer | true | 实际每页记录总数<br>每页记录展示的数目应大于0，小于等于1000（0<pageSize<=1000） |
| parentOrgIndexCodes | body | string | false | 父组织唯一标示集合，多个值使用英文逗号分隔，不超过1000个 |
| isSubOrg | body | boolean | false | true时，搜索parentOrgIndexCodes的所有子孙组织；<br>false时，只搜索直接子组织； |
| expressions | body | object[] | false | 查询表达式 |
| +key | Body | string | false | 资源属性名，key传updateTime，operator传between可以查询特定时间段更新的数据，考虑到校时和夏令时，建议值查询过去一天的数据变更 |
| +operator | Body | number | false | 操作运算符， 0 ：=， 1 ：>=， 2 ：<=， 3 ：in， 4 ：not in， 5 ：between， 6 ：like， 7 ：pre like， 8 ：suffix like |
| +values | Body | string[] | false | 资源属性值，=、>=、<=、like、values数组长度只能是1； in、not in，values数组长度大于1，最大不超时20； in_array用于查询key值有多个value的情况，例如行车监控添加的设备类型为encodeDevice、encodeDeviceMss两个类型，使用encodeDevice或者encodeDeviceMss都可以查询到； between只能用于整形、日期 ； like只能用于字符串。 |
| orderBy | body | string | false | 排序字段必须是查询条件，否则返回参数错误 |
