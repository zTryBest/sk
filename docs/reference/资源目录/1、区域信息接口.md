#### 查询区域列表v2

**接口说明**

> 根据查询条件查询区域列表信息，主要用于区域信息查询过滤。<br>相对V1接口，支持级联场景的区域查询<br><br>

**接口版本**

> v2

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/irds/v2/region/nodesByParams

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| resourceType | body | string | true | 资源类型;详见数据字典：<br>附录A.3 资源类型/资源权限码；<br>查询资源的类型，传region时查询的为用户有配置权限的区域树，传资源类型如：camera、encodeDevice查询用户对该类资源有权限的区域树；<br>注：资源iasDevice\reader\floor不进行权限校验，即不传authCodes |
| parentIndexCodes | body | string[] | false | 父编号集合;<br>String[]；<br>父编号个数<br><=1000个；<br>单个长度<=64Byte； |
| isSubRegion | body | boolean | false | 是否包含下级区域，true时，搜索parentIndexCodes的所有子、孙区域；<br>false时，只搜索parentIndexCodes的直接子区域； |
| pageNo | body | integer | true | 当前页码；pageNo≥1 |
| pageSize | body | integer | true | 分页大小；0<pageSize≤1000 |
| authCodes | body | string[] | false | 权限码集合;<br>String[]；详见数据字典<br>附录A.3 资源类型/资源权限码，<br>权限码个数<br><=20个；<br>单个权限码长度<br><=40Byte；<br>只有同时指定userId、authCodes时，才进行权限过滤；<br>当指定多个权限码时，只返回同时具有这些权限码的区域；<br> |
| regionType | body | integer | false | 区域类型，10-普通区域，11-级联区域，12-楼栋单元 |
| regionName | body | string | false | 区域名称；根据区域名称过滤，可模糊查询；<br>若包含中文，最大长度40，最大长度指不超过按照指定编码的字节长度，即getBytes("utf-8").length |
| sonOrgIndexCodes | body | string[] | false | 本级区域向上查询;<br>String[];场景：通过名称模糊查询资源点获取区域编号，并组成资源点的树形结构；<br>本级区域个数<br><=10个；<br>单个长度<=64Byte；<br>sonOrgIndexCodes集合中的多个区域只能为同一级目录； <br>当parentIndexCodes、regionType、regionName都为空时，才可根据sonOrgIndexCodes查询；<br> |
| cascadeFlag | body | integer | false | 级联标识，<br>0-全部，<br>1-本级，<br>2-级联，<br>默认0 |
| orderBy | body | string | false | 排序字段,注意：排序字段必须是查询条件，否则返回参数错误 |
| orderType | body | string | false | 降序升序,降序：desc，<br>升序：asc |
| expressions | body | object[] | false | 查询表达式 |
| +key | Body | string | false | 资源属性名，key传updateTime，operator传between可以查询特定时间段更新的数据，考虑到校时和夏令时，建议值查询过去一天的数据变更 |
| +operator | Body | number | false | 操作运算符， 0 ：=， 1 ：>=， 2 ：<=， 3 ：in， 4 ：not in， 5 ：between， 6 ：like， 7 ：pre like， 8 ：suffix like |
| +values | Body | string[] | false | 资源属性值，=、>=、<=、like、values数组长度只能是1； in、not in，values数组长度大于1，最大不超时20； in_array用于查询key值有多个value的情况，例如行车监控添加的设备类型为encodeDevice、encodeDeviceMss两个类型，使用encodeDevice或者encodeDeviceMss都可以查询到； between只能用于整形、日期 ； like只能用于字符串。 |

**请求参数举例**
```json
{
    "resourceType": "region",
    "parentIndexCodes": [
        "root000000"
    ],
    "isSubRegion": true,
    "pageNo": 1,
    "pageSize": 1,
    "authCodes": [
        "view"

    "regionType": 10,
    "regionName": "区",
    "sonOrgIndexCodes": [
        "root000000"

    "cascadeFlag": 0,
```

#### 根据区域编号获取下一级区域列表v2

**接口说明**

> 根据用户请求的资源类型和资源权限获取父区域的下级区域列表，主要用于逐层获取父区域的下级区域信息，例如监控点预览业务的区域树的逐层获取。下级区域只包括直接下级子区域。<br>注：<br>查询区域管理权限（resourceType为region），若父区域的子区域无权限、但是其孙区域有权限时，会返回该无权限的子区域，但是该区域的available标记为false（表示无权限）<br><br><br>

**接口版本**

> v2

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

> /api/resource/v2/regions/subRegions

**请求方法**

> POST

**数据提交方式**

> application/json

#### 批量添加区域

**接口说明**

> 支持区域的批量添加。<br>三方可以自行指定区域的唯一标识，也可以由ISC平台自行生成。<br>

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/resource/v1/region/batch/add

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| Array[0] | body | object | false | 待添加的区域列表，单次提交上限为1000条 |
| +clientId | Body | number | false | regionIndexCode为空时，regionIndexCode会由平台生成，三方用户需要通过clientid和regionIndexCode进行关联，再通过返回值中的clientId判断哪些成功，哪些失败。所以建议每次接口调用，clientid保持唯一。<br>注：clientid只对本次调用有效 |
| +regionIndexCode | Body | string | false | 区域唯一标志，不允许与其它区域唯一标志重复，包括已删除的区域，值为空或者不传此字段时系统自动生成唯一标志 |
| +parentIndexCode | Body | string | true | 父区域唯一标识码，根据[查询区域列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-区域信息接口#c2fdda08)接口获取返回报文中的indexCode字段 |

| +regionType | Body | number | true | 区域类型，10-普通区域，12-楼栋单元 |
