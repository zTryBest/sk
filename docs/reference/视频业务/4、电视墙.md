> 1.添加解码器和电视墙。<br>2.关联输出通道至电视墙上。<br>3.窗口已存在且设置为报警窗口<br>4.当前报警正在报警上墙<br>5.调用该接口停止报警上墙

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/tvms/v1/public/tvwall/alarm/deletion

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| event_index | body | string | true | 报警事件编号 |

**请求参数举例**
```json
{
    "event_index": "677BF56FA1AE4A9BB1308F57CA93C346"
}
```

**返回参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.1.2 电视墙错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#e3f824b2) |
| msg | body | string | false | 返回信息 |
| data | body | object | false | 返回数据 |

**返回参数举例**
```json
{
    "code": "0",
    "msg": "success",
    "data": {}
}
```

#### 获取电视墙窗口信息列表

**接口说明**

> 1.在电视墙客户端上添加解码器和电视墙，并关联解码器的输出通道至电视墙上。<br>2.在电视墙上进行开窗操作。<br>3.调用获取窗口列表信息接口。<br>

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/tvms/v1/tvwall/wnds/get

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| dlp_id | body | integer | false | 电视墙id，若为空，则返回该服务下所有窗口列表。<br>从[获取电视墙大屏信息](/docs/软件产品-综合安防管理平台-API列表-视频业务-电视墙#ebbb39e5)接口获取返回参数dlp_id |

**请求参数举例**
```json
{
    "dlp_id": 1
}
```

**返回参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.1.2 电视墙错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#e3f824b2) |
| msg | body | string | false | 返回信息 |
| data | body | object | false | 返回数据 |
| +wnd_list | body | object[] | false | 窗口信息列表 |
| ++wnd_id | body | number | false | 窗口编号 |
| ++wnd_uri | body | string | false | 窗口uri |
| ++status | body | number | false | 窗口上墙状态：0-空闲，1-上墙，2-轮巡，3-报警 |
| ++camera | body | object | false | 监控点信息 |
| +++index_code | body | string | false | 监控点唯一标识 |
| +++stream_url | body | string | false | 取流url |
| +++name | body | string | false | 监控点名称 |
| +++channel | body | number | false | 通道号 |
| +++stream_type | body | number | false | 码流类型，-1-平台码流 0-主码流 1-子码流 2-第三码流 |
| ++decoder | body | object | false | 解码资源信息 |
| +++id | body | number | false | 解码器编号 |
| +++name | body | string | false | 解码器名称 |
| +++index_code | body | string | false | 解码器indexCode |
| +++ip_addr | body | string | false | 解码器Ip |
| +++port | body | number | false | 解码器port |
| +++offline | body | boolean | false | true-离线，false-在线 |

**返回参数举例**
```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "wnd_list": [
            {
                "wnd_id": 16843777,
                "wnd_uri": "api/tvwall/1/device/1/floatwnd/16846849/subwnd/1",
                "status": 0,
                "camera": {
                    "index_code": "e7aaae828deb4ee1b88ca56788b6ce5b",
                    "stream_url": "null",
                    "name": "监控点1",
                    "channel": 1,
                    "stream_type": 0
                },
                "decoder": {
                    "id": 1,
                    "name": "解码设备1",
                    "index_code": "dec-0009727-af2096cf-e0b5-42d6-9d3f-7e74b79bf570",
```

#### 非开窗设备窗口分割

**接口说明**

> 1.添加解码器和电视墙。<br>2.关联输出通道至电视墙上。<br>3.调用该接口进行分割

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/tvms/v1/public/tvwall/monitor/division

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| dlp_id | body | integer | true | 电视墙id，从[获取电视墙大屏信息](/docs/软件产品-综合安防管理平台-API列表-视频业务-电视墙#ebbb39e5)接口获取返回参数dlp_id |
| monitor_pos | body | integer | true | 查看器pos,从[获取电视墙大屏信息](/docs/软件产品-综合安防管理平台-API列表-视频业务-电视墙#ebbb39e5)接口获取返回参数pos |
| div_num | body | integer | true | 分割数，支持：<br>1、2、4、6、8、9、12、16、25、36 |

**请求参数举例**
```json
{
    "dlp_id": 1,
    "monitor_pos": 1,
    "div_num": 4
}
```

**返回参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.1.2 电视墙错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#e3f824b2) |
| msg | body | string | false | 返回信息 |
| data | body | object | false | 返回数据 |
| +output_id | body | number | false | 输出通道编号 |
| +index | body | number | false | 输出通道indexCode |
| +subwnd_num | body | number | false | 子窗口数 |
| +pos | body | number | false | 输出在大屏上的位置，按从左到右，从上到下，0开始的编号 |
| +monitor_name | body | string | false | 输出通道的名称 |
| +joint | body | boolean | false | 标记是否已拼接 |
| +dlp_id | body | number | false | 关联的电视墙编号 |
| +dlp_row | body | number | false | 电视墙行数 |
| +dlp_col | body | number | false | 电视墙列数 |

**返回参数举例**
```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "output_id": 1,
        "index": 22,
        "subwnd_num": 4,
        "pos": 1,
        "monitor_name": "VGA_1",
        "joint": false,
        "dlp_id": 1,
        "dlp_row": 2,
        "dlp_col": 2
    }
}
```
