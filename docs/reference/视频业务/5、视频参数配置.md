#### 设置视频叠加字符串参数

**接口说明**

> 本接口用于设置视频叠加字符串参数，每个监控点最多支持叠加4条字符串，每次设置会全覆盖之前设置的字符串信息。仅支持海康SDK、ehome两种协议的监控点，且级联点位不支持该功能。<br>注意：参数设置是否生效与设备支持情况有关，不同型号设备支持情况不同。本接口设置的Y坐标值和下发到设备中的值可能存在不一致的情况，设备端叠加字符串的Y坐标是有限制的，SDK协议下发是4字节对齐的，下发的值会进行转换成16的倍数。原因为：防止P制和N制切换时Y坐标的的较大偏移；叠加字符串的最小字体就是16*16，如果Y坐标不做限制的话就会相互叠加在一块。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/video/v1/showStringParams/udpate

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| cameraIndexCode | body | string | true | 监控点唯一标识,从[分页获取监控点资源](/docs/软件产品-综合安防管理平台-API列表-视频应用服务-视频资源#ef459f4b)接口获取返回参数cameraIndexCode |
| showStringParams | body | object[] | true | 叠加字符串信息列表，最多叠加4条字符串，每次设置会全覆盖上次设置的字符串 |
| +showString | Body | string | true | 叠加字符串文本内容；注意海康SDK限制其数组长度为44，故最大允许设置43个字符 |
| +isShow | Body | number | true | 是否显示叠加内容，0-不显示；1-显示 |
| +xPos | Body | number | true | 显示X坐标 |
| +yPos | Body | number | true | 显示Y坐标 |

**请求参数举例**
```json
{
    "cameraIndexCode": "fee3d641f0e44ecCC9b9def2b423b7eb",
    "showStringParams": [
        {
            "showString": "camera 01",
            "isShow": 1,
            "xPos": 16,
            "yPos": 16
        }
    ]
}
```

**返回参数**

| 参数名称 | 参数位置 | 数据类型 | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.1.1 视频应用错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#a6aaa89a) |
| msg | body | string | false | 返回描述 |
| data | body | string | false | 返回数据 |

**返回参数举例**
```json
{
    "code": "0",
    "msg": "success",
    "data": null
}
```
