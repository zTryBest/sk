##### 查询账户记录

**接口说明**

> 该接口可以查询人员账户的记录，支持按照人员唯一标示、交易类型、时间段查询人员账户记录信息

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/cems/v1/account/log/search

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| startTime | body | string | true | 记录开始时间，ISO8601格式: <br>yyyy-MM-ddTHH:mm:ss+当前时区，例如北京时间：<br>2018-07-26T15:00:00 + 08:00<br>开始时间和结束时间最大跨度控制在30天 |
| endTime | body | string | true | 记录结束时间，ISO8601格式: <br>yyyy-MM-ddTHH:mm:ss+当前时区，例如北京时间：<br>2018-07-26T15:00:00 + 08:00<br>开始时间和结束时间最大跨度控制在30天 |
| transactionTypes | body | string | false | 账户交易类型： 1：充值 2：退款 3：补贴 4：纠正 5：消费扣款 6：补贴账户清空，多个用","隔开 |
| personId | body | string | false | 人员唯一ID，根据[查询人员列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员及照片接口#dd9d9d0b)接口获取返回报文中的personId字段 |
| cardNo | body | string | false | 卡号，根据[获取卡片列表](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员卡片接口#ab775d82)接口获取返回报文中的cardId字段 |
| pageNo | body | integer | true | 当前页码，pageNo>0 |
| pageSize | body | integer | true | 每页记录数，0<pageSize<=1000 |

**请求参数举例**

```json
{
    "startTime": "2018-07-26T15:00:00+08:00",
    "endTime": "2018-07-26T15:00:00+08:00",
    "transactionTypes": "1,2,3,4,5",
    "personId": "HZ12345",
    "cardNo": "122222333",
    "pageNo": 1,
    "pageSize": 20
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.2.6 食堂消费错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#ba9d72c7) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +total | body | number | false | 查询总数 |
| +totalPage | body | number | false | 总页数 |
| +page | body | number | false | 页码 |
| +pageSize | body | number | false | 页大小 |
| +rows | body | object[] | false | 返回对象列表 |
| ++personId | body | string | false | 人员唯一ID |
| ++personName | body | string | false | 人员姓名 |
| ++orgName | body | string | false | 人员所属组织名 |
| ++accountType | body | string | false | 账户类型 |
| ++deduction | body | number | false | 扣款金额，单位：分 |
| ++balance | body | number | false | 当前余额，单位：分 |
| ++debitTime | body | string | false | 交易时间，ISO8601格式：<br>yyyy-MM-ddTHH:mm:ss+当前时区，例如北京时间：<br>2018-07-26T15:00:00 + 08:00 |
| ++transactionType | body | number | false | 账户交易类型：<br>1：充值<br>2：退款<br>3：补贴<br>4：纠正<br>5：消费扣款<br>6：补贴账户清空 |
| ++typeName | body | string | false | 交易类型名称 |
| ++remark | body | string | false | 备注 |

**返回参数举例**

```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "total": 1,
        "totalPage": 1,
        "page": 1,
        "pageSize": 20,
        "rows": [
            {
                "personId": " HZ12345",
                "personName": "张三",
                "orgName": "默认组织",
                "accountType": "普通账户",
                "deduction": 100,
                "balance": 100,
                "debitTime": "2018-07-26T15:00:00+08:00",
                "transactionType": 5,
                "typeName": "消费扣款",
                "remark": "备注"
            }
        ]
    }
}
```

##### 消费账户充值

**接口说明**

> 该接口可以通过账户类型、卡号或人员唯一ID对人员普通/补贴账户进行充值。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/cems/v1/account/recharge

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| personId | body | string | false | 人员唯一ID，如为空则cardNo不允许为空，如果人员Id和卡号同时不为空，按人员Id来充值，根据[查询人员列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员及照片接口#dd9d9d0b)接口获取返回报文中的personId字段 |
| cardNo | body | string | false | 卡号,由刷卡终端设备触发读取的卡号，如为空则personId不允许为空，根据[获取卡片列表](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员卡片接口#b0343a3c)接口获取返回报文中的cardId字段 |
| money | body | integer | true | 充值金额,单位:分,范围0 < money < 10000000 |
| accountType | body | integer | true | 账户类型,账户类型:<br>1.普通账户<br>2.补贴账户 |
| rechargeId | body | string | true | 充值唯一编号，重复编号只充值一次 |

**请求参数举例**

```json
{
    "personId": "h18oqjdfv80148ydx8h8y58180",
    "cardNo": "1234567864",
    "money": 2000,
    "accountType": 1,
    "rechargeId": "abcdefg-hijklmn-opq-rst"
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.2.6 食堂消费错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#ba9d72c7) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +personName | body | string | false | 账户所属人员名称 |
| +genAccount | body | number | false | 普通账户金额，单位：分 |
| +money | body | number | false | 充值金额,单位:分,范围0 < money < 10000000 |
| +subAccount | body | number | false | 补贴账户金额，单位：分 |
| +totalAccount | body | number | false | 账户总金额，单位：分 |

**返回参数举例**

```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "personName": "张三",
        "genAccount": 100,
        "money": 100,
        "subAccount": 200,
        "totalAccount": 300
    }
}
```

> /api/cems/v1/account/balance/search

> POST

**数据提交方式**

> application/json

| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +personName | body | string | false | 账户所属人员名称 |
| +genAccount | body | number | false | 普通账户金额，单位：分 |
| +subAccount | body | number | false | 补贴账户金额，单位：分 |
| +totalAccount | body | number | false | 账户总金额，单位：分 |

**返回参数举例**

```json
{

    "msg": "success",

        "subAccount": 200,
        "totalAccount": 300
    }
}
```

##### 查询消费记录

**接口说明**

> 该接口可以查询人员消费的记录，支持按照人员唯一标示、卡号、消费模式、上报时间段查询人员消费记录信息。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/cems/v1/consume/log/search

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| startTime | body | string | true | 记录开始时间，ISO8601格式yyyy-MM-ddTHH:mm:ss+当前时区，例如北京时间：<br>2018-07-26T15:00:00 + 08:00<br>开始时间和结束时间最大跨度控制在30天 |
| endTime | body | string | true | 记录结束时间，ISO8601格式yyyy-MM-ddTHH:mm:ss+当前时区，例如北京时间：<br>2018-07-26T15:00:00 + 08:00<br>开始时间和结束时间最大跨度控制在30天 |
| chargeTypes | body | string | false | 消费模式：<br>1：计次模式<br>3：金额模式<br>多个用","隔开 |
| personId | body | string | false | 人员唯一ID  |
| cardNo | body | string | false | 人员卡号 |
| pageNo | body | integer | true | 当前页码，pageNo>0 |
| pageSize | body | integer | true | 页大小，0<pageSize<=1000 |

**请求参数举例**

```json
{
    "startTime": "2018-07-26T15:00:00+08:00",
    "endTime": "2018-07-26T15:00:00+08:00",
    "chargeTypes": "1,3",
    "personId": "HZ12345",
    "cardNo": "12333355554",
    "pageNo": 1,
    "pageSize": 20
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败 |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +total | body | number | false | 查询总数 |
| +page | body | number | false | 页码 |
| +pageSize | body | number | false | 页大小 |
| +firstPage | body | boolean | false | 是否为第一页 |
| +lastPage | body | boolean | false | 是否为最后一页 |
| +hasPreviousPage | body | boolean | false | 是否有上一页 |
| +hasNextPage | body | boolean | false | 是否有下一页 |
| +totalPage | body | number | false | 总页数 |
| +rows | body | object[] | false | 返回对象列表 |
| ++chargeNo | body | string | false | 账单流水号 |
| ++cardNo | body | string | false | 卡号，由刷卡终端设备触发读取的卡号 |
| ++personId | body | string | false | 人员唯一ID |
| ++preAccount | body | number | false | 扣款前余额，单位：分 |
| ++merchantName | body | string | false | 消费商户 |
| ++deduction | body | number | false | 扣款金额，单位：分 |
| ++balance | body | number | false | 当前余额，单位：分 |
| ++debitTime | body | string | false | 交易时间，ISO8601格式：<br>yyyy-MM-ddTHH:mm:ss+当前时区，例如北京时间：2018-07-26T15:00:00 + 08:00 |
| ++personName | body | string | false | 人员姓名 |
| ++orgName | body | string | false | 人员所属组织名 |
| ++consumeTerminalNo | body | string | false | 消费终端的终端号 |
| ++times | body | number | false | 消费次数 |
| ++chargeType | body | number | false | 消费模式：<br>1：计次模式<br>3：金额模式 |
