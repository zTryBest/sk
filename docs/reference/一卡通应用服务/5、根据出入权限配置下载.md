##### 创建下载任务_根据出入权限配置下载

**接口说明**

> 创建下载任务，以异步任务方式根据权限配置异动（对权限未下载、下载失败、变更的数据重新下发）下载出入控制权限。适用于通过服务管理配置权限的情况，适用综合大楼、学校、医院等批量权限下载的场景<br>创建下载任务，使得业务组件与出入控制权限服务建立一次异步下载的通道。<br>任务类型支持组合下载方式，只要有一个类型符合时即可下载权限（即任务类型与设备能力集取交集）。<br>通过向下载任务中添加数据接口添加待下载的设备通道数据；可分多次调用该接口批量添加下载数据；当不调用添加数据接口，直接开始下载任务时，自动根据业务组件已配置的权限信息，对未下载成功的权限条目下载。<br>任务的操作权限由创建的业务组件控制，包含开始下载任务，终止下载任务，删除下载任务。<br>建议业务组件在设置回调地址接收时，异步处理内部逻辑，避免请求超时（5秒超时）<br>新创建的下载任务有效期7天，在7天内未操作开始下载的任务将自动清理。<br>tagId用于让多个应用共用出入控制权限服务时，用以区分各自的下载任务。建议使用组件标识。<br>每个tagId全局默认最多保持100个可操作（未下载结束）任务列表。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/acps/v1/download/configuration/task/add

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| taskType | body | integer | true | 下载任务类型<br>1：卡片<br>4：人脸<br>其他参考[附录A.53 任务下载类型说明](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#c4c7357d) |

**请求参数举例**

```json
{
    "taskType": 1
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.2.3 出入控制权限错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#c3be41a7) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回结果 |
| +taskId | body | string | false | 下载任务唯一标识 |

**返回参数举例**

```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "taskId": "02e66ac47a03481fa0f304fa3acfa773"
    }
}
```

##### 按人员与设备下载

**接口说明**

> 接口支持权限配置完成后，下发或重置某个人员或设备的权限。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.5.0及以上版本

**接口地址**

> /api/acps/v1/authDownload/configuration/person/reset

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| resourceInfos | body | object[] | false | 资源对象列表 |
| +resourceIndexCode | Body | string | true | 资源的唯一标识，资源为设备，[查询资源列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-资源信息接口#da53ed76)接口获取返回报文中的indexCode字段 |
| +resourceType | Body | string | true | 资源类型，详见[附录A.50 设备通道类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#d98f04ce) |
| +channelNos | Body | number[] | false | 资源通道号，<br>当资源类型为设备时，无特殊说明必填。<br>传参数说明：<br>表示此次数据需要配置/下载到设备的哪些通道上；<br>门禁的人证设备、可视对讲设备等无通道的设备，默认通道号为1； |
| personIds | body | string[] | true | 人员编号列表 |
| isReset | body | boolean | false | 是否重置权限(默认只下未下发数据) |

**请求参数举例**

```json
{
    "resourceInfos": [
        {
            "resourceIndexCode": "0a869b06f4ff4da29949acf006405c39",
            "resourceType": "acsDevice",
            "channelNos": [
                1
            ]
        }
    ],
    "personIds": [
        "37835310f786451a8eb55d6c43b827cc"
    ],
    "isReset": false
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.2.3 出入控制权限错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#c3be41a7) |
| msg | body | string | false | 返回描述 |

**返回参数举例**

```json
{
    "code": "0",
    "msg": "success"
}
```

##### 添加待下载的设备通道_根据出入权限配置下载

**接口说明**

> 选择要下发的设备或点位的所有人权限。<br>如果不调用此接口，代表下发所有人的所有设备和所有资源点的权限。<br>该接口支持向新建的下载任务中添加待下载的权限数据，可通过本接口分多次向下载任务中添加数据。<br>该接口强依赖于资源目录公共存储，请确保设备与人员相关的信息已存在公共存储，否则下载必定失败。<br>数据添加完成后必须调用 开始下载任务接口 才能下发权限。<br>单次接口最多支持100个设备通道对象。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/acps/v1/download/configuration/data/add

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| taskId | body | string | true | 下载任务唯一标识，创建任务处获取 |
| resourceInfos | body | object[] | false | 资源对象 |
| +resourceIndexCode | Body | string | true | 资源的唯一标识，资源为设备，[查询资源列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-资源信息接口#da53ed76)接口获取返回报文中的personId字段 |
| +resourceType | Body | string | true | 资源类型，详见[附录A.50 设备通道类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#d98f04ce) |
| +channelNos | Body | number[] | false | 资源通道号 |

**请求参数举例**

```json
{
    "taskId": "02e66ac47a03481fa0f304fa3acfa773",
    "resourceInfos": [
        {
            "resourceIndexCode": "0a869b06f4ff4da29949acf006405c39",
            "resourceType": "acsDevice",
            "channelNos": [
                1
            ]
        }
    ]
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.2.3 出入控制权限错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#c3be41a7) |
| msg | body | string | false | 返回描述 |
| data | body | string | false | 无返回结果 |

**返回参数举例**

```json
{
    "code": "0",
    "msg": "success",
    "data": "null"
}
```
