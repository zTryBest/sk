##### 查询出入事件

**接口说明**

> 该接口可以查询发生在门口机、围墙机上的人员出入事件，支持多个维度来查询，支持按时间、人员、设备、卡号、事件类型五个维度来查询；其中按事件类型来查询的方式，如果查询不到事件，存在两种情况，一种是该类型的事件没有发生过，所以查询不到，还有一种情况，该类型的事件发生过，但是由于可视对讲管理组件对该事件类型订阅配置处于关闭状态，所以不会存储该类型的事件，导致查询不到，对于这种情况，需要到可视对讲管理组件中，将该事件类型的订阅配置打开。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.2及以上版本

**接口地址**

> /api/vis/v1/accessEvent/events

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| startTime | body | string | true | 开始时间（事件开始时间，采用ISO8601时间格式，与endTime配对使用，不能单独使用） |
| endTime | body | string | true | 结束时间（事件结束时间，采用ISO8601时间格式，与startTime配对使用，不能单独使用） |
| eventTypes | body | string | false | 事件类型（10进制，需根据事件类型定义表中类型进行转换。参考[附录D.2.2.1 可视对讲事件类型](/docs/软件产品-综合安防管理平台-附录-附录D 事件列表-附录D2 一卡通事件-附录D2.2 可视对讲事件#df39f22a) |
| personIds | body | string | false | 人员ID集（最大支持10个人员搜索），[获取人员列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员及照片接口#aa136eca)接口返回报文中的personId字段 |
| cardNos | body | string | false | 卡号集（最大支持10张卡片搜索），多个以逗号隔开， [获取卡片列表](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口人员信息接口-人员卡片接口#ab775d82)接口获取返回参数cardNo |
| deviceIds | body | string | false | 设备编号集（最大支持10个设备集搜索），多个以逗号隔开， [查询可视对讲设备列表v2](/docs/软件产品-综合安防管理平台-API列表-一卡通应用服务-可视对讲#cbb3c30a)接口获取返回参数indexCode |
| sort | body | string | false | 排序字段（支持personName、deviceName、eventTime填写排序的字段名称，与order配对使用，不能单独使用，例如："personName"） |
| order | body | string | false | 升/降序（指定排序字段是使用升序（asc）还是降序（desc），与sort配对使用，不能单独使用，例如："asc"） |
| pageNo | body | integer | true | 起始页（pageNo>0） |
| pageSize | body | integer | true | 当前页大小（0<pageSize<=1000） |
**请求参数举例**

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0：成功，其它参考[附录E.2.4 可视对讲管理错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#f02eeb23) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据（具体接口返回信息结构，此处为事件分页数据） |

| ++deviceIndexCode | body | string | false | 设备编码 |
| ++svrIndexCode | body | string | false | 图片存储服务的唯一标识 |

##### 获取出入事件的图片

**接口说明**

> 通过该接口根据输入的图片的相对Uri地址，可以获取到具体的数据数据。<br>此接口返回Http Status 302 重定向，所以参数返回与其他接口有些差异。本接口的应答描述是图片存储服务器的返回信息。<br>

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.2及以上版本

**接口地址**

> /api/vis/v1/accessEvent/eventPictures

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| svrIndexCode | body | string | true | 存储接入服务（图片服务器唯一标识），获取picUri处会提供此参数 |
| picUri | body | string | true | 图片地址 |
**请求参数举例**
```json
{
    "svrIndexCode": "a517ab45-09bf-423c-83fe-fea3b6332292",
    "picUri": "/pic?=d62i7f6e*6a7i125-c838b9--a8c67dea96e65icb1*=sd*=5dpi*=1dpi*m2i1t=4ed35444bb4s=-39z422d3"
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，[附录E.2.4 可视对讲管理错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#f02eeb23) |
