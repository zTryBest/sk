##### 查询门禁点事件v2

**接口说明**

> 功能描述：该接口可以查询发生在门禁点上的人员出入事件，支持多个维度来查询，支持按时间、人员、门禁点、事件类型四个维度来查询；其中按事件类型来查询的方式，如果查询不到事件，存在两种情况，一种是该类型的事件没有发生过，所以查询不到，还有一种情况，该类型的事件发生过，但是由于门禁管理组件对该事件类型订阅配置处于关闭状态，所以不会存储该类型的事件，导致查询不到，对于这种情况，需要到门禁管理组件中，将该事件类型的订阅配置打开。

**接口版本**

> v2

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/acs/v2/door/events

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| pageNo | body | integer | true | 当前页码（pageNo>0） |
| pageSize | body | integer | true | 每页展示数目（0<pageSize<=1000） |
| doorIndexCodes | body | string[] | false | 门禁点唯一标识数组，最大支持10个门禁点，[查询门禁点列表v2](/docs/软件产品-综合安防管理平台-API列表-一卡通应用服务-门禁管理#b40ec5e7)接口获取返回报文中的doorIndexCode字段 |

| startTime | body | string | false | 开始时间（事件开始时间，采用ISO8601时间格式，与endTime配对使用，不能单独使用，时间范围最大不能超过3个月，与receiveStartTime二选一必填），参考附录B ISO8601时间格式说明|
| endTime | body | string | false | 结束时间（事件结束时间，采用ISO8601时间格式，最大长度32个字符，与startTime配对使用，不能单独使用，时间范围最大不能超过3个月，与receiveEndTime二选一必填），参考附录B ISO8601时间格式说明 |

| receiveEndTime | body | string | false | 入库结束时间，采用ISO8601时间格式，最大长度32个字符，与receiveStartTime配对使用，不能单独使用，时间范围最大不能超过3个月，与endTime二选一必填，参考附录B ISO8601时间格式说明 |
| doorRegionIndexCodes | body | string[] | false | 门禁点所在区域列表，最大支持500个区域 |
| eventTypes | body | integer[] | false | 事件类型，参考[附录D2.1 门禁事件](/docs/软件产品-综合安防管理平台-附录-附录D 事件列表-附录D2 一卡通事件-附录D2.1 门禁事件) |
| personName | body | string | false | 人员姓名(支持中英文字符，不能包含 ' / \ : * ? " < > |，支持模糊搜索,长度不超过32位) |
| personIds | body | string[] | false | 人员数组（最大支持100个人员） |
| sort | body | string | false | 排序字段（支持personName、doorName、eventTime填写排序的字段名称） |
| order | body | string | false | 升/降序（指定排序字段是使用升序（asc）还是降序（desc） |

##### 查询门禁点状态

**接口说明**

> 该接口支持门常开、门常闭、门开和门闭四种操作引起的门状态获取。门常开操作，门会一直处于开状态，不会自动关闭，执行门闭操作，门才会关上；门常闭操作，门会一直处于关毕状态，普通卡刷卡门不会被打开，执行门开操作，门会打开；门开操作，执行门打开动作，超过门打开时间，门会自动关上；门闭操作，执行关门动作，会立即把门关上。<br>调用该接口，首先要通过获取门禁点资源列表的接口，获取到门禁点唯一编号，然后根据门禁点唯一编号进行门禁点状态状态查询。需要注意的是门通道必须接上门磁才能正常发送门状态变化通知，如果未接门磁，平台无法通过门状态变更通知来更新门状态。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/acs/v1/door/states

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
|  doorIndexCodes  | body | string[] | false | 门禁点唯一标识，最大支持200个门禁点。[查询门禁点列表v2](/docs/软件产品-综合安防管理平台-API列表-一卡通应用服务-门禁管理#b40ec5e7)接口获取返回参数doorIndexCode |

**请求参数举例**

```json
{
    "doorIndexCodes": [
        "1f276203e5234bdca08f7d99e1097bba"
    ]
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其它参考[附录E.2.1 门禁管理错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#ffa8694a) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +authDoorList | body | object[] | false | 有权限的门禁点状态集合 |
| ++doorIndexCode | body | string | false | 门禁点indexCode |
| ++doorState | body | number | false | 门状态，0 初始状态，1 开门状态，2关门状态，3离线状态 |
| +noAuthDoorIndexCodeList | body | string[] | false | 没有权限的门禁点集合 |

**返回参数举例**

```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "authDoorList": [
            {
                "doorIndexCode": "e8e3ef5c149243abb4341124ab38fcfc",
                "doorState": 0
            }
        ],
        "noAuthDoorIndexCodeList": [
            "e8e3ef5c149243abb4341124ab38fcfc"
        ]
    }
}
```

##### 门禁点反控

**接口说明**

> 该接口支持门常开、门常闭、门开和门闭四种操作。门常开操作，门会一直处于开状态，不会自动关闭，执行门闭操作，门才会关上；门常闭操作，门会一直处于关毕状态，普通卡刷卡门不会被打开，执行门开操作，门会打开；门开操作，执行门打开动作，超过门打开时间，门会自动关上；门闭操作，执行关门动作，会立即把门关上。<br>调用该接口，首先要通过获取门禁点资源列表的接口，获取到门禁点唯一编号，然后根据门禁点唯一编号进行反控操作，该接口支持单个和多个门禁点操作，如果所有门禁点反控操作成功，则返回成功，其他情况都返回失败，在失败的情况下，会按每个门禁点返回对应的错误。<br>

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.0及以上版本

**接口地址**

> /api/acs/v1/door/doControl

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| doorIndexCodes | body | string[] | true | 门禁点唯一标识，最大支持10个门禁点。[查询门禁点列表v2](/docs/软件产品-综合安防管理平台-API列表-一卡通应用服务-门禁管理#b40ec5e7)接口获取返回参数doorIndexCode |
| controlType | body | integer | true | 0-常开<br>1-门闭<br>2-门开<br>3-常闭 |

**请求参数举例**

```json
{
    "doorIndexCodes": [
        "1f276203e5234bdca08f7d99e1097bba"
    ],
    "controlType": 3
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其它参考[附录E.2.1 门禁管理错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#ffa8694a) |
| msg | body | string | false | 返回描述<br>（记录接口执行情况说明信息） |
| data | body | object[] | false | 返回数据（具体接口返回信息结构，此处为反控结果信息） |
| +doorIndexCode | body | string | false | 门禁点唯一标识 |
| +controlResultCode | body | number | false | 0标识反控成功，其他表示失败，见附录E.3 门禁管理错误码说明 |
| +controlResultDesc | body | string | false | 与controlResultCode对应的描述，见附录E.3 门禁管理错误码说明 |

**返回参数举例**

```json
{
    "code": "0",
    "msg": "success",
    "data": [
        {
            "doorIndexCode": "2c95c028a809448f962a969ebd3ab34f",
            "controlResultCode": 0,
            "controlResultDesc": "success"
        }
    ]
}
```
