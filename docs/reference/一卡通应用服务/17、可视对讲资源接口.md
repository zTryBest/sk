##### 增量获取可视对讲设备数据

**接口说明**

> 根据资源类型、时间段增量获取资源，包含已删除数据。资源密码以*代替，其中开始日期与结束日期的时间差必须在1-48小时内。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/resource/v1/visDevice/timeRange

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| startTime | body | string | true | 开始日期,格式：yyyy-MM-dd'T'HH:mm:ss.SSS |
| endTime | body | string | false | 截止日期,格式：yyyy-MM-dd'T'HH:mm:ss.SSS |
| pageNo | body | integer | true | 页码,pageNo≥1 |
| pageSize | body | integer | true | 页面大小,0<pageSize≤1000 |
**请求参数举例**
```json
{
    "startTime": "2019-08-06T14:01:17.839+0800",
    "endTime": "2019-08-06T16:01:17.839+0800",
    "pageNo": 1,
    "pageSize": 1000
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.other.1 资源目录错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#b3d660a8) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +total | body | number | false | 记录总数 |
| +list | body | object[] | false | 资源数据列表 |
| ++resourceType | body | string | false | 资源类型 |
| ++indexCode | body | string | false | 资源唯一编码 |
| ++name | body | string | false | 资源名称 |
| ++deviceType | body | string | false | 设备系列 |
| ++deviceModel | body | string | false | 设备型号 |
| ++deviceCode | body | string | false | 主动设备编号 |
| ++dataVersion | body | string | false | 版本号 |
| ++manufacturer | body | string | false | 厂商 |
| ++longNum | body | string | false | 设备长号 |
| ++regionIndexCode | body | string | false | 所属区域 |
| ++treatyType | body | string | false | 接入协议，详见[附录A.6 编码设备接入协议](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#d4852837) |
| ++installLocation | body | string | false | 安装位置 |
| ++visMainManager | body | number | false | 0非主管理机  |
| ++devSerialNum | body | string | false | 设备的序列号 |
| ++sort | body | number | false | 显示顺序 |
| ++createTime | body | string | false | 创建时间 |
| ++updateTime | body | string | false | 更新时间 |
| ++description | body | string | false | 描述 |
**返回参数举例**
```json
{
    "code": "0",
    "msg": "SUCCESS",
    "data": {
        "total": 3,
        "list": [
            {
                "resourceType": "visDevice",
                "indexCode": "213123100000",
                "name": "资源1",
                "deviceType": "ek",
                "deviceModel": "12",
                "deviceCode": "0129900000000001",
                "dataVersion": "V1.2",
                "manufacturer": "hik",
                "longNum": "311113",
                "regionIndexCode": "d8a5476e-25c0-4aa2-b7e3-CC3788ba1f77",
                "treatyType": "hiksdk_net",
                "installLocation": "Location1",
                "visMainManager": 0,
                "devSerialNum": "afy8293823",
                "sort": 1,
                "createTime": "2018-11-28T16:47:27:358+08:00",
                "updateTime": "2018-11-28T16:48:34:011+08:00",
                "description": "描述"
```

##### 查询可视对讲设备列表v2

**接口说明**

> 根据条件查询目录下有权限的可视对讲设备列表。

**接口版本**

> v2

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/resource/v2/visDevice/search

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| name | body | string | false | 名称，模糊搜索，最大长度32，若包含中文，最大长度指不超过按照指定编码的字节长度，即getBytes("utf-8").length |
| regionIndexCodes | body | string[] | false | 区域编号,可以为空;<br>String[]，支持根据区域批量查询；<br>区域编号个数<br><=1000个；<br>单个长度<=64Byte；，可从[查询区域列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-区域信息接口#c2fdda08)接口获取返回参数indexCode |
| isSubRegion | body | boolean | false | true时，搜索regionIndexCodes及其子孙区域的资源；<br>false时，只搜索 regionIndexCodes的资源；<br>isSubRegion不为空，regionIndexCodes也不可为空 |
| pageNo | body | integer | true | 当前页码 |
| pageSize | body | integer | true | 分页大小 |
| authCodes | body | string[] | false | 权限码集合，详见[附录A.3 资源权限码](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#c92e73ec) |
| capabilitySet | body | array | false | 设备能力集(含设备上的智能能力)，详见[附录A.44 设备能力集](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#e043207b) |
| expressions | body | object[] | false | 查询表达式 |
| +key | Body | string | false | 资源属性名，key传updateTime，operator传between可以查询特定时间段更新的数据，考虑到校时和夏令时，建议值查询过去一天的数据变更 |
| +operator | Body | number | false | 操作运算符， 0 ：=， 1 ：>=， 2 ：<=， 3 ：in， 4 ：not in， 5 ：between， 6 ：like， 7 ：pre like， 8 ：suffix like |
| +values | Body | string[] | false | 资源属性值，=、>=、<=、like、values数组长度只能是1； in、not in，values数组长度大于1，最大不超时20； in_array用于查询key值有多个value的情况，例如行车监控添加的设备类型为encodeDevice、encodeDeviceMss两个类型，使用encodeDevice或者encodeDeviceMss都可以查询到； between只能用于整形、日期 ； like只能用于字符串。 |
| orderBy | body | string | false | 排序字段,注意：排序字段必须是查询条件，否则返回参数错误 |
| orderType | body | string | false | 降序升序,降序：desc 升序：asc |
**请求参数举例**
```json
{
    "name": "test",
    "regionIndexCodes": [
        "8fyc8qw8280y0y43"
    ],
    "isSubRegion": true,
    "pageNo": 1,
    "pageSize": 1,
    "authCodes": [
        "view"
    ],
    "capabilitySet": ["support_card"],
    "expressions": [
        {
            "key": "indexCode",
            "operator": 0,
            "values": [
                "ayd8y80y1y082ye01y2e8"
            ]
        }
    ],
    "orderBy": "name",
    "orderType": "desc"
}
```
