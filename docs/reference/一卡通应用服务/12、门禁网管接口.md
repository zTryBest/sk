##### 获取门禁设备在线状态

**接口说明**

> 根据条件获取门禁设备在线状态接口

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/nms/v1/online/acs_device/get

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| regionId | body | string | false | 区域唯一标志，根据[查询区域列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-区域信息接口#c2fdda08)接口获取返回报文中的indexCode字段 |
| ip | body | string | false | 设备ip |
| indexCodes | body | string[] | false | 编码列表，最大500 |
| status | body | string | false | 状态，1-在线，0-离线，-1-未检测 |
| pageNo | body | integer | false | 页码，从1开始，不填默认为1 |
| pageSize | body | integer | false | 页大小，正整数，不填默认为10 |
| includeSubNode | body | string | false | 是否包含下级，1包含，0不包含（若regionId为空，则该参数不起作用） |

**请求参数举例**

```json
{
    "regionId": "root000000",
    "ip": "10.33.43.135",
    "indexCodes": [
        "f98y8c28y85y7y213c082yu95yu"
    ],
    "status": "1",
    "pageNo": 1,
    "pageSize": 20,
    "includeSubNode": "1"
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.other.4 网管错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#ea9272d6) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 数据信息 |
| +pageNo | body | number | false | 页码 |
| +pageSize | body | number | false | 每页记录数 |
| +totalPage | body | number | false | 总页数 |
| +total | body | number | false | 总记录数 |
| +list | body | object[] | false | 资源信息集 |
| ++deviceType | body | string | false | 设备型号 |
| ++deviceIndexCode | body | string | false | 设备唯一编码 |
| ++regionIndexCode | body | string | false | 区域编码 |
| ++collectTime | body | string | false | 采集时间 |
| ++regionName | body | string | false | 区域名字 |
| ++indexCode | body | string | false | 资源唯一编码 |
| ++cn | body | string | false | 设备名称 |
| ++treatyType | body | string | false | 协议类型，<br>海康私有协议：hiksdk_net，<br>GB/T28181：<br>gb_reg,<br>eHome协议：ehome_reg，<br>大华私有协议：dhsdk_net，<br>ONVIF协议：onvif_net，<br>萤石协议：<br>ezviz_net，<br>级联：<br>cascade |
| ++manufacturer | body | string | false | 厂商，hikvision-海康，dahua-大华 |
| ++ip | body | string | false | ip地址 |
| ++port | body | number | false | 端口 |
| ++online | body | number | false | 在线状态，0离线，1在线 |

**返回参数举例**

```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "pageNo": 1,
        "pageSize": 10,
        "totalPage": 0,
        "total": 1,
        "list": [
            {
                "deviceType": "HIK%2FDS-9116HW-ST%2F-AF-DVR",
                "deviceIndexCode": "null",
                "regionIndexCode": "ce91c758-5af4-4539-845a",
                "collectTime": "2018-12-28T10:21:40.000+08:00",
                "regionName": "NMS自动化",
                "indexCode": "82896441ced946d5a51c6d6ca8e65851",
                "cn": "Onvif-IPC(10.67.172.13 )",
                "treatyType": "onvif_net",
                "manufacturer": "hikvision",
                "ip": "10.67.172.13",
                "port": 80,
                "online": 1
            }
        ]
    }
}
```
