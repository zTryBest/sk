##### 查询设备通道权限下载记录列表

**接口说明**

> 根据查询条件分页查询设备通道的下载记录(包括计划模板的下载记录)，只能查询由业务组件自身创建的任务下载记录。下载记录主要展示此次下载的概览信息，可通过查询设备通道的下载记录详情接口查询每个设备通道中人员的下载详情。<br>支持通过任务编号查询单个任务的下载记录。<br>支持通过设备通道查询设备通道的历史下载记录（卡权限下载记录只能通过设备查询，人脸、指纹下载可通过设备和通道查询）。<br>支持通过任务编号、设备通道对象、下载时间、下载类型查询历史下载记录。<br>该接口仅返回分页的列表数据，不返回总数。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.3及以上版本

**接口地址**

> /api/acps/v1/download_record/channel/list/search

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| taskId | body | string | false | 下载任务唯一标识，创建任务时获得 |
| resourceInfos | body | object[] | false | 设备通道对象列表 |
| +resourceIndexCode | Body | string | true | 资源的唯一标识，资源为设备，[查询资源列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-资源信息接口#da53ed76)接口获取返回报文中的personId字段 |
| +resourceType | Body | string | true | 资源类型，详见[附录A.50 设备通道类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#d98f04ce) |
| +channelNos | Body | number[] | false | 通道号 |
| taskTypes | body | integer[] | false | 下载任务类型<br>1：卡片<br>4：人脸<br>其他详见[附录A.53 任务下载类型说明](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#c4c7357d) |
| downloadResult | body | integer | false | 下载结果，<br>0成功，<br>1失败，<br>2部分成功 |
| downloadStartTime | body | object | false | 下载开始时间查询对象 |

| +endTime | Body | string | false | 结束日期，采用ISO8601时间格式，最大长度32个字符，如2018-09-03T17:30:08+08:00 |
| downloadEndTime | body | object | false | 下载结束时间查询对象 |
| +startTime | Body | string | false | 结束日期，采用ISO8601时间格式，最大长度32个字符，如2018-09-03T17:30:08+08:00 |
| +endTime | Body | string | false | 结束日期，采用ISO8601时间格式，最大长度32个字符，如2018-09-03T17:30:08+08:00 |
| sortObjects | body | object[] | false | 排序对象，目前只支持下载开始与结束时间排序 |
| +field | Body | string | false | 排序字段 |
| +sort | Body | string | false | 排序规则，asc：正序，<br>desc：倒序 |
| pageNo | body | integer | true | 页码，pageNo>0 |

| downloadResultId | body | string | false | 下载记录唯一ID,使用downloadResultId查询设备通道下载记录详情时，忽略taskId与resourceInfo字段（"下载记录唯一ID"和"下载任务标识+设备通道对象"两者必须有一个不为空），从[查询设备通道权限下载记录列表](/docs/软件产品-综合安防管理平台-API列表-一卡通应用服务-一卡通权限管理#faa5eb84)接口获取返回参数downloadResultId |
| taskId | body | string | false | 下载任务唯一标识,，从[查询设备通道权限下载记录列表](/docs/软件产品-综合安防管理平台-API列表-一卡通应用服务-一卡通权限管理#faa5eb84)接口获取返回参数taskId |
| resourceInfo | body | object | false | 设备通道对象列表 |
| +resourceIndexCode | Body | string | true | 资源的唯一标识，资源为设备，[查询资源列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-资源信息接口#da53ed76)接口获取返回报文中的personId字段 |
| +resourceType | Body | string | true | 资源类型，详见[附录A.50 设备通道类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#d98f04ce) |
| +channelNos | Body | number[] | false | 通道号，当资源类型为设备时，无特殊说明必填 |
| personIds | body | string[] | false | 人员编号列表，[查询人员列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-人员信息接口-人员及照片接口#dd9d9d0b)接口获取返回报文中的personId字段 |

| downloadResult | body | integer | false | 下载结果，<br>0 成功，<br>1 失败，<br>2 部分成功 |
| downloadTime | body | object | false | 下载时间查询对象 |
