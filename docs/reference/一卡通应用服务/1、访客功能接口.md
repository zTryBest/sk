##### 获取访客基础信息字段

**接口说明**

> 获取访客基础信息字段（包含自定义字段）信息

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/visitor/v1/visitorInfo/field

**请求方法**

> POST

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 - 成功，其他- 失败，参考附录E.2.2 访客管理错误码 |
| msg | body | string | false | 返回描述 |
| data | body | object[] | false | 返回信息 |
| +name | body | string | false | 参数名 |
| +id | body | string | false | 参数key |
| +showType | body | string | false | 参数类型 文本框-1、下拉框-2、时间框-3、图片框-6、单选框-7、文本框-8、多选框-10 |
| +hint | body | string | false | 表单项的提示信息 |
| +regular | body | string | false | 表单项的校验正则 |
| +dataValue | body | object[] | false | 取值范围 |
| ++text | body | string | false | 参数值说明 |
| ++value | body | number | false | 参数值 |
| ++selected | body | boolean | false | 是否默认 |
| +required | body | boolean | false | 是否必填 |
| +display | body | boolean | false | 是否可见 |
| +visitorFieldType | body | string | false | 字段类型,自定义字段-1、基础信息字段-0 |
| +fieldCatalog | body | string | false | 字段类别，common=常用信息，custom=自定义，antiepidemic=防疫 |
| +elementType | body | string | false | 前端显示控件类型 input=文本输入框，select=下拉选择，date_picker=日期选择，picture=图片框，radio=单选框，textarea=文本框，checkbox=多选框 |

<br><br>


##### 获取访客记录中的图片

**接口说明**

> 获取访客记录中的图片，重定向后返回图片流

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.0及以上版本

**接口地址**

> /api/visitor/v1/record/pictures

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| svrIndexCode | body | string | true | 图片存储服务的唯一标识，提供picUri处会提供此字段 |
| picUri | body | string | true | 图片相对地址 |

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 - 成功，其他- 失败，参考附录E.2.2 访客管理错误码 |
| msg | body | string | false | 返回描述 |
| data | body | string | false | 为空 |
