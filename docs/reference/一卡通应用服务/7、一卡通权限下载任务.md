##### 开始下载任务

**接口说明**

> 该接口用于开始一次下载任务，只能由创建任务的组件触发。权限下载完成后会自动结束下载任务。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.2及以上版本

**接口地址**

> /api/acps/v1/authDownload/task/start

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| taskId | body | string | true | 下载任务唯一标识，创建任务时获取 |

**请求参数举例**

```json
{
    "taskId": "02e66ac47a03481fa0f304fa3acfa773"
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.2.3 出入控制权限错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#c3be41a7) |
| msg | body | string | false | 返回描述 |
| data | body | string | false | 无返回结果 |

**返回参数举例**

```json
{
    "code": "0",
    "msg": "success",
    "data": "null"
}
```

##### 查询下载任务进度

**接口说明**

> 根据任务ID查询任务的下载进度，只能查询由组件创建的任务，进度信息包含任务总体下载进度及各个资源的下载进度。<br>建议该接口调用频率每3-5秒查询一次任务的下载进度。<br>

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.2及以上版本

**接口地址**

> /api/acps/v1/authDownload/task/progress

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| taskId | body | string | true | 下载任务唯一标识，创建任务时获取 |

**请求参数举例**

```json
{
    "taskId": "02e66ac47a03481fa0f304fa3acfa773"
}
```

##### 查询任务信息列表

**接口说明**

> 该接口用于分页查询任务的详细信息

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.5及以上版本

**接口地址**

> /api/acps/v1/authDownload/task/search

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| authTaskIds | body | string[] | false | 下载任务唯一标志，创建任务时获取 |
| authTaskStatusList | body | integer[] | false | 任务状态，0-未下载，1-下载中，2-下载完成 |
| operationTypeList | body | integer[] | false | 下载任务操作类型，详见[附录A.82 任务操作类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#a7231d54) |
| taskTypeList | body | integer[] | false | 下载任务类型列表，详见[附录A.53 任务下载类型说明](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#c4c7357d) |
| pageNo | body | integer | true | 页码，pageNo>0 |
| pageSize | body | integer | true | 分页大小，0<pageSize<=1000 |

**请求参数举例**

```json
{
    "authTaskIds": [
        "46f2328384064eec905fcd77d64c7bb0"
    ],
    "authTaskStatusList": [
        1
    ],
    "operationTypeList": [
        1
    ],
    "taskTypeList": [
        4
    ],
    "pageNo": 1,
    "pageSize": 10
}
```

**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.2.3 出入控制权限错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#c3be41a7) |

| data | body | object | false | 返回数据 |
| +total | body | number | false | 总条数 |
| +pageSize | body | number | false | 分页大小 |
| +pageNo | body | number | false | 页码 |
| +list | body | object[] | false | 任务详情列表 |
| ++authTaskId | body | string | false | 任务ID |
| ++createTime | body | string | false | 任务创建时间，采用ISO8601时间格式，如2019-09-03T17:30:08.000+08:00 |
| ++startTime | body | string | false | 任务开始时间，采用ISO8601时间格式，如2019-09-03T17:30:08.000+08:00 |
| ++endTime | body | string | false | 任务结束时间，采用ISO8601时间格式，如2019-09-03T17:30:08.000+08:00 |
