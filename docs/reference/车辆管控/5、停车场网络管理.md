#### 获取停车场设备在线状态

**接口说明**

> 根据条件获取停车场设备在线状态在线状态接口

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.5及以上版本

**接口地址**

> /api/nms/v1/online/pms/device/get

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| regionId | body | string | false | 区域编码，[查询区域列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-区域信息接口#c2fdda08)接口获取返回报文中的indexCode字段 |
| includeSubNode | body | string | false | 是否包含下级（1包含，0不包含） |
| resourceType | body | string | true | 设备类型，参考[附录A.88 停车场网管资源类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#b1fe1859) |
| indexCodes | body | string[] | false | 设备标识集合，从[获取资源列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-资源信息接口#cbc52c56)接口获取返回参数indexCode，多个用逗号隔开 |
| status | body | string | false | 状态，1-在线，0-离线，-1-未检测 |
| pageNo | body | integer | false | 页码，范围 ( 0 , ~ )，不填默认为1 |
| pageSize | body | integer | false | 页大小，范围 ( 0 , 1000 ]，不填默认为10 |
**请求参数举例**
```json
{
    "regionId": "CC29247a-3b60-4cf9-84d5-4d95fef9311f",
    "includeSubNode": "1",
    "resourceType": "cross",
    "indexCodes": [
        "tfgwc3254234ctg365435634v"
    ],
    "status": "0",
    "pageNo": 1,
    "pageSize": 100
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.other.4 网管错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#ea9272d6) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 数据信息 |
| +pageNo | body | number | false | 页码 |
| +pageSize | body | number | false | 每页记录数 |
| +totalPage | body | number | false | 总页数 |
| +total | body | number | false | 总记录数 |
| +list | body | object[] | false | 资源信息集 |
| ++deviceType | body | string | false | 设备型号 |
| ++deviceIndexCode | body | string | false | 设备唯一编码 |
| ++regionIndexCode | body | string | false | 区域编码 |
| ++collectTime | body | string | false | 采集时间 |
| ++regionName | body | string | false | 区域名字 |
| ++indexCode | body | string | false | 资源唯一编码 |
| ++cn | body | string | false | 设备名称 |
| ++treatyType | body | string | false | 协议类型， 海康私有协议： hiksdk_net， GB/T28181： gb_reg, eHome协议： ehome_reg， 大华私有协议： dhsdk_net， ONVIF协议： onvif_net， 萤石协议： ezviz_net， 级联： cascade |
| ++manufacturer | body | string | false | 厂商 |
| ++ip | body | string | false | ip地址 |
| ++port | body | number | false | 端口 |
| ++online | body | number | false | 在线状态，0离线，1在线 |
