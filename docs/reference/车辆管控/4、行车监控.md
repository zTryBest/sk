#### 查询车载设备列表

**接口说明**

> 查询目录下有权限的车载设备列表。<br>非必填入参若不传值则使用默认值作为查询限制条件，没有默认值的若不传值则不作为查询限制条件。<br>

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/resource/v1/encodeDeviceMss/search

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| name | body | string | false | 名称，模糊搜索，最大长度32，若包含中文，最大长度指不超过按照指定编码的字节长度，即getBytes("utf-8").length |
| regionIndexCodes | body | string[] | false | 区域编号,可以为空;<br>String[]，支持根据区域批量查询；<br>区域编号个数<br><=1000个；<br>单个长度<=64Byte；，可从[查询区域列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-区域信息接口#c2fdda08)接口获取返回参数indexCode |
| isSubRegion | body | boolean | false | true时，搜索regionIndexCodes及其子孙区域的资源，false时，只搜索 regionIndexCodes的资源，不传默认为false |
| pageNo | body | integer | true | 当前页码 |
| pageSize | body | integer | true | 分页大小 |
| expressions | body | object[] | false | 查询表达式 |
| +key | Body | string | false | 资源属性名，key传updateTime，operator传between可以查询特定时间段更新的数据，考虑到校时和夏令时，建议值查询过去一天的数据变更 |
| +operator | Body | number | false | 操作运算符， 0 ：=， 1 ：>=， 2 ：<=， 3 ：in， 4 ：not in， 5 ：between， 6 ：like， 7 ：pre like， 8 ：suffix like |
| +values | Body | string[] | false | 资源属性值，=、>=、<=、like、values数组长度只能是1； in、not in，values数组长度大于1，最大不超时20； in_array用于查询key值有多个value的情况，例如行车监控添加的设备类型为encodeDevice、encodeDeviceMss两个类型，使用encodeDevice或者encodeDeviceMss都可以查询到； between只能用于整形、日期 ； like只能用于字符串。 |
| orderBy | body | string | false | 排序字段,注意：排序字段必须是查询条件，否则返回参数错误 |
| orderType | body | string | false | 降序升序,降序：desc 升序：asc |
**请求参数举例**
```json
{
    "name": "test",
    "regionIndexCodes": [
        "8fyc8qw8280y0y43"
    ],
    "isSubRegion": true,
    "pageNo": 1,
    "pageSize": 1,
    "expressions": [
        {
            "key": "indexCode",
            "operator": 0,
            "values": [
                "ayd8y80y1y082ye01y2e8"
            ]
        }
    ],
    "orderBy": "name",
    "orderType": "desc"
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.other.1 资源目录错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#b3d660a8) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +total | body | number | false | 记录总数 |
| +pageNo | body | number | false | 当前页码 |
| +pageSize | body | number | false | 分页大小 |
| +list | body | object[] | false | 资源数据列表 |
| ++deviceKey | body | string | false | 设备驱动 |
| ++indexCode | body | string | false | 资源唯一编码 |
| ++manufacturer | body | string | false | 厂商 |
| ++name | body | string | false | 资源名称 |
| ++netZoneId | body | string | false | 网域 |
| ++port | body | string | false | 端口 |
| ++regionIndexCode | body | string | false | 所属区域indexCode |
| ++resourceType | body | string | false | 资源类型，encodeDeviceMss：车载设备，encodeDevice：编码设备 |
| ++treatyType | body | string | false | 接入协议，详见[附录A.6 编码设备接入协议](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#d4852837) |
| ++createTime | body | string | false | 创建时间，ISO8601标准 |
| ++updateTime | body | string | false | 更新时间，ISO8601标准 |
| ++dataVersion | body | string | false | 版本号 |
| ++description | body | string | false | 描述 |
| ++deviceKeyVersion | body | string | false | 设备驱动版本号 |
| ++regionName | body | string | false | 区域名称 |
| ++regionPath | body | string | false | 区域完整目录，@进行分割 |
| ++regionPathName | body | string | false | 区域目录名称，/进行分割 |

#### 查询设备的行驶路线

**接口说明**

> 该接口通过设备编码集合，开始时间，结束时间，用户等条件组合查询三个月内的车载设备行驶路线。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.5及以上版本

**接口地址**

> /api/mss/v1/gps/track/search

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| pageNo | body | integer | true | 页码，大于0 |
| pageSize | body | integer | true | 每页数据记录数，范围：[1,1000] |
| startTime | body | string | true | 路线查询的开始时间,三个月以内，格式：yyyy-MM-ddTHH:mm:ss+当前时区 |
| endTime | body | string | true | 路线查询的结束时间，最多查询一天24小时的路线，间距最多为24小时，格式：yyyy-MM-ddTHH:mm:ss+当前时区 |
| deviceIndexCodes | body | string[] | true | 需要查询路线的设备ID集合，最大1000个 |
**请求参数举例**
```json
{
    "pageNo": 1,
    "pageSize": 1000,
    "startTime": "2019-01-01T00:00:00+08:00",
    "endTime": "2019-01-01T00:00:00+08:00",
    "deviceIndexCodes": [
        "d9b1887e8e814a7d86648228cdea8150"
    ]
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.3 行车监控错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#cc55c736) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +pageNo | body | number | false | 当前页码 |
| +pageSize | body | number | false | 每页记录数 |
| +total | body | number | false | 总条数 |
| +totalPage | body | number | false | 总页数 |
| +list | body | object[] | false | 路线信息对象列表 |
| ++longitude | body | string | false | 经度，设备上报的原始坐标，会转成火星坐标（GCJ），然后再转成墨卡托 |
| ++latitude | body | string | false | 纬度，设备上报的原始坐标，会转成火星坐标（GCJ），然后再转成墨卡托 |
| ++timeStr | body | string | false | gps上报的时间，ISO8601时间格式，格式：yyyy-MM-ddTHH:mm:ss.SSS+当前时区 |
| ++speed | body | string | false | 车辆当前速度，单位：km/h，范围：[0,999] |
| ++deviceIndexCode | body | string | false | 设备编码 |
**返回参数举例**
```json
{
    "code": "0",
    "msg": "SUCCESS",
    "data": {
        "pageNo": 1,
        "pageSize": 10,
        "total": 0,
        "totalPage": 1,
        "list": [
            {
                "longitude": "13386043.496414",
                "latitude": "3542541.5378874",
                "timeStr": "2019-01-01T00:00:00.000+08:00",
                "speed": "30",
                "deviceIndexCode": "d9b1887e8e814a7d86648228cdea8150"
            }
        ]
    }
}
```
