| ++ownerName | body | string | false | 车主姓名，在车辆黑名单关联了人员的时候会返回值 |
| ++phone | body | string | false | 手机号码，在车辆黑名单关联了手机号码的时候会返回值 |
| ++reason | body | number | false | 布防原因，默认-1（全部原因），1（被盗车），2（被抢车），3（嫌疑车），4（交通违法车），5（紧急查控车） |
| ++description | body | string | false | 描述，当黑名单有描述的时候会返回值 |
