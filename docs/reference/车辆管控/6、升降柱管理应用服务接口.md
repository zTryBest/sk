#### 根据升降柱控制盒编号控制升降柱

**接口说明**

> 根据升降柱控制盒编号控制升降柱

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V2.1.0及以上版本

**接口地址**

> /api/lcmas/v1/deviceControl

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| command | body | integer | true | 控制命令，1-上升，2-下降，3-停止 |
| bollardIndexCode | body | string | true | 升降柱控制盒唯一标识码，可以调用【查询资源列表v2】接口查询，资源类型传"securitycheck"，或者详见附录数据字典说明(数据字典中需要补充控制盒的类型说明) |
**请求参数举例**
```json
{
   "command":1,
   "bollardIndexCode":"zdfsdfsd2323"
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | true | 返回请求结果码 |
| message | body | string | true | 提示信息 |
**返回参数举例**
```json
{
    "code": "0",
    "message": "success"
}
```
