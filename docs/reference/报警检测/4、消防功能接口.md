**接口说明**

> 查询目录下有权限的消防设备列表。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.4及以上版本

**接口地址**

> /api/resource/v1/fireDevice/search

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| name | body | string | false | 名称，模糊搜索，最大长度32，若包含中文，最大长度指不超过按照指定编码的字节长度，即getBytes("utf-8").length |
| regionIndexCodes | body | string[] | false | 区域编号,可以为空;<br>String[]，支持根据区域批量查询；<br>区域编号个数<br><=1000个；<br>单个长度<=64Byte；，可从[查询区域列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-区域信息接口#c2fdda08)接口获取返回参数indexCode |
| isSubRegion | body | boolean | false | true时，搜索regionIndexCodes及其子孙区域的资源；<br>false时，只搜索 regionIndexCodes的资源 |
| pageNo | body | integer | true | 当前页码 |
| pageSize | body | integer | true | 分页大小 |
| orderBy | body | string | false | 排序字段,注意：排序字段必须是查询条件，否则返回参数错误 |
| orderType | body | string | false | 降序升序,降序：desc 升序：asc |
| expressions | body | object[] | false | 查询表达式 |
| +key | Body | string | false | 资源属性名，key传updateTime，operator传between可以查询特定时间段更新的数据，考虑到校时和夏令时，建议值查询过去一天的数据变更 |
| +operator | Body | number | false | 操作运算符， 0 ：=， 1 ：>=， 2 ：<=， 3 ：in， 4 ：not in， 5 ：between， 6 ：like， 7 ：pre like， 8 ：suffix like |
| +values | Body | string[] | false | 资源属性值，=、>=、<=、like、values数组长度只能是1； in、not in，values数组长度大于1，最大不超时20； in_array用于查询key值有多个value的情况，例如行车监控添加的设备类型为encodeDevice、encodeDeviceMss两个类型，使用encodeDevice或者encodeDeviceMss都可以查询到； between只能用于整形、日期 ； like只能用于字符串。 |

        {
