##### 查询消防传感器部件状态v2

**接口说明**

> 分页查询消防传感器部件状态。

**接口版本**

> v2

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.5及以上版本

**接口地址**

> /api/fpnms/v2/sensor/status/search

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| includeSubNode | body | integer | true | 是否包含下级 (1-包含、0-不包含) |
| regionIndexCode | body | string | true | 所属区域indexCode，根据[查询区域列表v2](/docs/软件产品-综合安防管理平台-API列表-资源目录-区域信息接口#c2fdda08)接口获取返回报文中的indexCode字段 |
| cn | body | string | false | 传感器名称 |
| channelType | body | integer | false | 传感器类型，详见[附录A.57 消防传感器大类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#fba6cd37) |
| unitStatus | body | integer | false | 部件状态，0：未注册 1：正常 2: 修复中 3：异常状态（修复中状态目前没用到，未注册时设备没有在离线状态） 空-所有状态 |
| channelIndexCode | body | string | false | 传感器编号 |
| pageNo | body | integer | true | 目标页码，默认从1开始，表示第一页 |
| pageSize | body | integer | true | 每页记录数，每页最大数量1000,默认20 |
**请求参数举例**
```json
{
    "includeSubNode": 1,
    "regionIndexCode": "04c60702-f555-4887-9ae8-dc1186a7537a",
    "cn": "园区传感器",
    "channelType": 1020008,
    "unitStatus": 1,
    "channelIndexCode": "124afdva41a753",
    "pageNo": 1,
    "pageSize": 20
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[附录E.4.2 消防错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#f2b69923) |
| msg | body | string | false | 返回描述 |
| data | body | object | false | 返回数据 |
| +pageSize | body | number | false | 每页条数 |
| +total | body | number | false | 结果总数 |
| +page | body | number | false | 页码 |
| +totalPage | body | number | false | 总页数 |
| +rows | body | object[] | false | 返回结果集 |
| ++cn | body | string | false | 传感器名称 |
| ++indexCode | body | string | false | 传感器编码 |
| ++regionIndexCode | body | string | false | 所属区域 |
| ++regionName | body | string | false | 区域目录名称，"\\"分隔 |
| ++channelIndexCode | body | string | false | 传感器编号 |
| ++channelType | body | number | false | 传感器大类型，详见[附录A.57 消防传感器大类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#fba6cd37) |
| ++channelSubType | body | string | false | 传感器小类型，详见[附录A.56 消防传感器小类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#aee9bebb) |
| ++unitStatus | body | number | false | 部件状态，0：未注册 1：正常 2: 修复中 3：异常状态（修复中状态目前没用到，未注册时设备没有在离线状态） 空-所有状态 |
| ++collectTime | body | string | false | 更新时间，IOS8601格式 |
| ++parentName | body | string | false | 父资源名称 |
| ++faultType | body | string | false | 故障类型，","号分隔，详见[附录A.89 消防故障类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#ca931162) |
| ++faultName | body | string | false | 故障类型名称，","号分隔 |
| ++faultNum | body | string | false | 故障次数 |
**返回参数举例**
```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "pageSize": 20,
        "total": 1,
        "page": 1,
        "totalPage": 1,
        "rows": [
            {
                "cn": "园区用传传感器",
                "indexCode": "2b3cf996ecf0449ebfa25c3b2935c07f",
                "regionIndexCode": "04c60702-f555-4887-9ae8-dc1186a7537a",
                "regionName": "根节点/消防设备/2",
                "channelIndexCode": "123",
                "channelType": 1020004,
                "channelSubType": "23",
                "unitStatus": 1,
                "collectTime": "2019-01-15T16:08:16.587+08:00",
                "parentName": "33-2",
                "faultType": "254065",
                "faultName": "主电故障",
                "faultNum": "1"
            }
        ]
    }
}
```
