##### 紧急报警事件日志查询

**接口说明**

> 用户可以使用该接口查询事件日志，该接口提供条件筛选功能， 包括开始时间、结束时间、事件源名称、事件源类型等。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.5及以上版本

**接口地址**

> /api/escpms/v1/eventLogs/searches

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| pageNo | body | integer | true | 当前页码，0 < pageNo |
| pageSize | body | integer | true | 每页数据数，0 < pageSize≤1000 |
| eventType | body | integer | false | 10进制事件码，紧急报警：327687 |
| srcName | body | string | false | 事件源名称 |
| startTime | body | string | false | 开始时间，采用ISO8601时间格式 |
| endTime | body | string | false | 结束时间，采用ISO8601时间格式 |
**请求参数举例**
```json
{
    "pageNo": 1,
    "pageSize": 800,
    "eventType": 327687,
    "srcName": "紧急报警柱",
    "startTime": "2018-04-02T08:00:00.000+08:00",
    "endTime": "2018-04-02T08:00:00.000+08:00"
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[ 附录E.4.4 紧急报警错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#d0e19c41) |
| msg | body | string | false | 返回描述-记录接口执行情况说明信息 |
| data | body | object | false | 返回数据 |
| +total | body | number | false | 查询数据记录总数 |
| +pageNo | body | number | false | 当前页码 |
| +pageSize | body | number | false | 每页记录总数 |
| +hasNextPage | body | boolean | false | 是否有下一页 |
| +list | body | object[] | false | 事件对象列表 |
| ++eventId | body | string | false | 事件唯一标志 |
| ++startTime | body | string | false | 开始时间，采用ISO8601时间格式 |
| ++endTime | body | string | false | 结束时间，采用ISO8601时间格式 |
| ++regionName | body | string | false | 事件源所属区域目录，多级以"/"隔开 |
| ++srcName | body | string | false | 事件源名称 |
| ++srcType | body | string | false | 事件源资源类型，详见[附录A.84 报警设备类型](/docs/软件产品-综合安防管理平台-附录-附录A 数据字典#b7d7e700) |
| ++eventType | body | number | false | 事件类型，327687：紧急报警 |
| ++srcIndex | body | string | false | 事件源indexCode |
| ++srcParentIndex | body | string | false | 事件源所属设备id |
| ++status | body | number | false | 事件状态，0-瞬时 1-开始  2-停止  3-事件脉冲   4-事件联动结果更新 |
**返回参数举例**
```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "total": 1,
        "pageNo": 1,
        "pageSize": 100,
        "hasNextPage": false,
        "list": [
            {
                "eventId": "adc70079-9b79-471c-9f3e-8e55fb6915e4",
                "startTime": "2018-04-02T08:00:00.000+08:00",
                "endTime": "2018-04-03T08:00:00.000+08:00",
                "regionName": "Root Node/321/123",
                "srcName": "紧急报警柱",
                "srcType": "polePanic",
                "eventType": 327687,
                "srcIndex": "88a2b70ac6ac44a5ab25787280b86ea1",
                "srcParentIndex": "f8b8b2d89316453883b9349391c44651",
                "status": 2
            }
        ]
    }
}
```

##### 根据事件源编号查询监控点信息

**接口说明**

> 根据事件源的防区通道编号，查询所属设备的监控点信息，包括监控点id和名称。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.5及以上版本

**接口地址**

> /api/escpms/v1/channel/camera

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| indexCode | body | string | true | 事件源通道编号，，[紧急报警事件日志查询](/docs/软件产品-综合安防管理平台-API列表-报警检测-紧急报警#c714c2a4)接口获取返回参数srcIndex |
**请求参数举例**
```json
{
    "indexCode": "242b84ceae2f483cace50df7ed7acaab"
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | false | 返回码，0 – 成功，其他- 失败，参考[ 附录E.4.4 紧急报警错误码](/docs/软件产品-综合安防管理平台-附录-附录E 返回码说明-返回码说明#d0e19c41) |
| msg | body | string | false | 返回描述-记录接口执行情况说明信息 |
| data | body | object | false | 返回数据 |
| +deviceIndexCode | body | string | false | 所属设备编号 |
| +deviceName | body | string | false | 所属设备名称 |
| +cameras | body | object[] | false | 监控点信息 |
| ++indexCode | body | string | false | 通道编号 |
| ++channelName | body | string | false | 通道名称 |
**返回参数举例**
```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "deviceIndexCode": "a78f02hc30uy49uc293arc2083c",
        "deviceName": "设备1",
        "cameras": [
            {
                "indexCode": "cr80w0c90290c49029034c32rcatc",
                "channelName": "通道"
            }
        ]
    }
}
```
