#### 单个添加重点目标识别计划

**接口说明**

> a)该接口可以新增一条重点目标识别计划，以实现将若干抓拍点抓拍到的人脸，通过若干识别资源同若干分组内的人脸比较，并将命中结果以事件形式上报。<br>b)配置一条识别计划需要人脸分组集合（通过"按条件查询人脸分组"接口获取），抓拍点集合（通过LDAP服务获取监控点，并通过型号确定抓拍点），识别资源集合（通过"按条件查询识别资源"接口获取）。<br>c)一条重点人员识别计划只能配置一种识别资源类别：海康深眸或脸谱或超脑。<br>d)一条重点人员识别计划，可以配置多个超脑作为识别资源或一个脸谱作为识别资源。<br>e)一条重点人员识别计划如果配置海康深眸作为识别资源，则recognitionResourceIndexCodes可以传空。因为海康深眸的抓拍点就是识别资源本身，智能监控应用服务会根据抓拍点自动匹配正确的识别资源。<br>f)智能监控应用服务会校验抓拍点的有效性。校验规则如下：超脑作为识别资源时，抓拍点必须是超脑的通道；脸谱作为识别资源时，脸谱作为识别资源时，抓拍点一般为海康深眸或其他人脸相机通道；海康深眸作为识别资源时，抓拍点必须是海康深眸的通道；一个通道是否是海康深眸/超脑/抓拍机的通道，取决于通道所属设备的型号，详见详见附录I 智能监控应用服务支持设备型号列表。<br>g)重点人员识别计划配置有以下限制，这些限制会在添加时作为特殊错误返回：超脑的一个通道只能配置一次重点人员识别计划；同一个抓拍点不能同时配置在多个脸谱上；抓拍点或识别资源没有同步到IAC前，无法配置识别计划。<br>h)识别计划的配置为异步过程，调用接口成功后，智能监控应用服务会在后台自动下发人脸分组并执行布防操作，可以通过接口"单个查询重点人员识别计划详情"查询该识别计划的下发结果。<br>i) 识别计划支持配置时间计划模板，当时间计划参数不传时，默认全天候。当传入此参数时，时间计划规则如下：按周计划进行配置，每一天的时间段上限为8，每一个时间段的开始时间必须小于结束时间。<br>j)同一个海康深眸支持配置多个识别计划。<br>k)若设备上人脸分组达到上限，则有可能导致下发失败。

#### 单个添加陌生人识别计划

**接口说明**

> a)该接口可以新增一条重点人员识别计划，以实现将若干抓拍点抓拍到的人脸，通过若干识别资源同若干分组内的人脸比较，并将命中结果以事件形式上报。<br>b)配置一条识别计划需要人脸分组集合（通过"按条件查询人脸分组"接口获取），抓拍点集合（通过LDAP服务获取监控点，并通过型号确定抓拍点），识别资源集合（通过"按条件查询识别资源"接口获取）。<br>c)一条重点人员识别计划只能配置一种识别资源类别：海康深眸或脸谱或超脑。<br>d)一条重点人员识别计划，可以配置多个超脑作为识别资源或一个脸谱作为识别资源。<br>e)一条重点人员识别计划如果配置海康深眸作为识别资源，则recognitionResourceIndexCodes可以传空。因为海康深眸的抓拍点就是识别资源本身，智能监控应用服务会根据抓拍点自动匹配正确的识别资源。<br>f)智能监控应用服务会校验抓拍点的有效性。校验规则如下：超脑作为识别资源时，抓拍点必须是超脑的通道；脸谱作为识别资源时，脸谱作为识别资源时，抓拍点一般为海康深眸或其他人脸相机通道；海康深眸作为识别资源时，抓拍点必须是海康深眸的通道；一个通道是否是海康深眸/超脑/抓拍机的通道，取决于通道所属设备的型号，详见详见附录I 智能监控应用服务支持设备型号列表。<br>g)重点人员识别计划配置有以下限制，这些限制会在添加时作为特殊错误返回：超脑的一个通道只能配置一次重点人员识别计划；同一个抓拍点不能同时配置在多个脸谱上；抓拍点或识别资源没有同步到IAC前，无法配置识别计划。<br>h)识别计划的配置为异步过程，调用接口成功后，智能监控应用服务会在后台自动下发人脸分组并执行布防操作，可以通过接口"单个查询重点人员识别计划详情"查询该识别计划的下发结果。<br>i) 识别计划支持配置时间计划模板，当时间计划参数不传时，默认全天候。当传入此参数时，时间计划规则如下：按周计划进行配置，每一天的时间段上限为8，每一个时间段的开始时间必须小于结束时间。<br>j)同一个海康深眸支持配置多个识别计划。<br>k)若设备上人脸分组达到上限，则有可能导致下发失败。

#### 单个添加人脸分组

**接口说明**

> a)一次性添加一个人脸分组，返回结果为添加成功的人脸分组。<br>

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center V1.2及以上版本

**接口地址**

> /api/frs/v1/face/group/single/addition

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| name | body | string | false | 人脸分组的名称，1~32个字符；不能包含 ' / \\ : * ? " < > | 这些特殊字符；智能监控应用服务会对分组名称进行重复性校验 |
| description | body | string | false | 分组的描述，1~128个字符 |
**请求参数举例**
```json
{
    "name": "仓库值守人员",
    "description": "仓库值守人员是指守着仓库的人"
}
```

| data | body | object | false | 人脸分组 |
| +indexCode | body | string | false | 人脸分组的唯一标识,由智能监控应用服务生成 |

| +description | body | string | false | 人脸分组的描述 |
**返回参数举例**
