## 事件通知机制

平台支持以下事件通知方式：

### 1. MQTT 订阅
- 客户端通过 MQTT 协议连接平台消息中间件
- 订阅指定 topic 接收事件推送
- 适用场景：实时性要求高的业务

### 2. HTTP 回调
- 在平台配置回调 URL
- 事件触发时平台主动 POST 事件数据到回调地址
- 适用场景：服务端集成

### 3. 事件轮询
- 调用事件服务接口主动查询事件
- 适用场景：非实时场景或事件回溯

## 通用报文结构

所有事件遵循统一的报文格式：

```json
{
    "method": "OnEventNotify",
    "params": {
        "ability": "<事件类别>",
        "events": [{
            "eventId": "<事件唯一标识 UUID>",
            "eventType": "<事件类型码>",
            "happenTime": "<ISO8601时间>",
            "srcIndex": "<事件源编号>",
            "srcType": "<事件源类型>",
            "status": "<事件状态>",
            "timeout": "<超时时间>"
        }],
        "sendTime": "<发送时间>"
    }
}
```

### 事件状态码

| 状态码 | 含义 |
|--------|------|
| 0 | 瞬时事件 |
| 1 | 事件开始 |
| 2 | 事件停止 |
| 3 | 事件脉冲 |
| 4 | 事件联动结果更新 |
| 5 | 异步图片上传 |
