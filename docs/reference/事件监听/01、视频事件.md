# 视频事件

> 所属产品：综合安防管理平台（iSecure Center）V2.1.1
> 事件来源：附录D.1 视频事件
> 消息协议：MQTT / HTTP回调（OnEventNotify）

## 事件通知通用格式

### 请求参数

| 参数名称 | 数据类型 | 属性描述 | 是否必填 | 最大长度 | 备注 |
|----------|----------|----------|----------|----------|------|
| method | String | 方法名 | 是 | 64 | 事件固定 `OnEventNotify` |
| params | Params | 事件参数信息 | 是 | 不限 | 具体参数信息见下方 |

### Params 属性说明

| 参数名称 | 数据类型 | 属性描述 | 是否必填 | 最大长度 | 备注 |
|----------|----------|----------|----------|----------|------|
| sendTime | String | 事件发出时间 | 是 | 64 | ISO8601格式 |
| ability | String | 事件类别 | 是 | 64 | `event_vss`(视频事件) / `event_io`(报警输入输出) / `event_rule`(智能规则) / `event_gps`(GPS事件) |
| events | Events[] | 事件信息 | 是 | 不限 | 事件详情数组 |

### Events 属性说明

| 参数名称 | 数据类型 | 属性描述 | 是否必填 | 最大长度 | 备注 |
|----------|----------|----------|----------|----------|------|
| eventId | String | 事件唯一标识 | 是 | 64 | 同一事件上报多次时eventId相同 |
| srcIndex | String | 事件源编号 | 是 | 64 | 物理设备资源编号 |
| srcType | String | 事件源类型 | 是 | 64 | camera等 |
| srcName | String | 事件源名称 | 否 | 64 | |
| srcParentIndex | String | 父设备编码 | 否 | 64 | |
| eventType | Number | 事件类型 | 是 | 32 | 见下方事件类型码 |
| status | Number | 事件状态 | 是 | 32 | 0-瞬时 1-开始 2-停止 3-脉冲 4-联动结果更新 5-异步图片上传 |
| eventLvl | Number | 事件等级 | 否 | 32 | 0-未配置 1-低 2-中 3-高 |
| timeout | Number | 脉冲超时时间 | 是 | 32 | 单位：秒 |
| happenTime | String | 事件发生时间 | 是 | 64 | ISO8601（设备时间） |
| data | Object | 扩展数据 | 否 | - | 智能事件附加数据 |
