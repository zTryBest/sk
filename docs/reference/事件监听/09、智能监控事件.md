# 智能监控事件

> 所属产品：综合安防管理平台（iSecure Center）V2.1.1
> 事件来源：附录D.5.1 智能监控事件

---

## 事件类型码

| 事件名称 | 事件类型码 | 说明 |
|----------|------------|------|
| 人脸采集事件 | 131614 | 人脸抓拍采集 |
| 人脸比对事件 | 131659 | 人脸识别比对结果 |
| 重点目标识别事件 | 1644175361 | 重点人员目标识别 |
| 陌生人识别事件 | 1644171265 | 陌生人检测告警 |
| 高频目标识别事件 | 132865 | 高频出现目标告警 |
| 人体事件 | 262144 | 人体检测事件 |
| 车辆事件 | 131622 | 车辆检测事件 |

---

## 说明

智能监控事件主要涵盖**人脸识别**和**车辆识别**两大智能分析领域：

- **人脸相关事件**：人脸采集、人脸比对、重点目标识别、陌生人识别、高频目标识别等
- **人体事件**：人体检测与目标结构化信息
- **车辆事件**：车辆检测与目标结构化信息

这些事件通过智能分析服务产生，可用于人脸布控、陌生人告警、重点人员轨迹追踪等安防场景。
