### 临时作业预约创建

**接口说明**

> 该接口可以创建区域临时作业，指定作业人员，平台管理员审批后可以对作业人员下发区域权限。

**接口版本**

> v1

**接口适配产品版本**

> 综合安防管理平台iSecure Center 1.3.0及以上版本

**接口地址**

> /api/acsopac/v1/temporary/work/create

**请求方法**

> POST

**数据提交方式**

> application/json

**请求参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| areaCode | body | string | true | 区域编号，可通过查询封闭区域列表接口获取。 |
| workName | body | string | true | 临时作业名称，长度为1~32个字符,支持中英文字符、数字，不能包含 /:*?<>|等特殊字符。 |
| workDesc | body | string | false | 临时作业内容描述，长度为1~32个字符,支持中英文字符、数字，不能包含 /:*?<>|等特殊字符。 |
| principalPersonId | body | string | true | 作业负责人personId，可通过人员信息查询接口，如查询人员列表v2接口获取。 |
| peerPersonId | body | string[] | false | 作业随行人，最多可添加10人 |
| workStartTime | body | string | true | 作业开始时间，时间参数需满足ISO8601格式如："2022-10-24T17:30:08.000+08:00" |
| workEndTime | body | string | true | 作业结束时间，时间参数需满足ISO8601格式如："2022-10-24T17:30:08.000+08:00" |
**请求参数举例**
```json
{
    "areaCode": "28790ece-fd64-4c86-b800-f100be0CC3e3",
    "workName": "临时作业api接口测试",
    "workDesc": "临时作业api接口测试描述",
    "principalPersonId": "bb1188a70694402fa10fedff0463051f",
    "peerPersonId": [
        "f53908c665f0454a978feb69ac5a054f"
    ],
    "workStartTime": "2022-10-15T17:30:08.000+08:00",
    "workEndTime": "2022-10-15T18:30:08.000+08:00"
}
```
**返回参数**

| 参数名称  | 参数位置  | 数据类型  | 是否必须 | 参数描述                                     |
| --------------- | --------- | --------- | ---- | ---------------------------------------- |
| code | body | string | true | 返回码 |
| msg | body | string | true | 返回消息 |
| data | body | object | true | 返回数据 |
| +workId | body | number | true | 临时作业id |
**返回参数举例**
```json
{
    "code": "0",
    "msg": "success",
    "data": {
        "workId": 8
    }
}
```
