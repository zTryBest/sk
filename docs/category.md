## 四、事件监听

> 事件是平台主动推送的消息，用于通知业务系统设备状态变化、告警等信息。
> 支持 MQTT 订阅 / HTTP 回调 / 事件轮询 三种通知方式。

### 通用事件报文结构

```json
{
    "method": "OnEventNotify",
    "params": {
        "ability": "<事件类别>",
        "events": [{
            "eventId": "<UUID>",
            "eventType": "<事件类型码>",
            "happenTime": "<ISO8601>",
            "srcIndex": "<事件源编号>",
            "srcType": "<事件源类型>",
            "status": "<0瞬时|1开始|2停止|3脉冲|4联动|5图片>",
            "timeout": "<超时秒数>"
        }],
        "sendTime": "<ISO8601>"
    }
}
```
